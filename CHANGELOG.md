# Changelog

## 0.2.1

- Point repository and homepage links at the renamed GitHub repo.

## 0.2.0

- React (`form-uploader/react`) and Vue (`form-uploader/vue`) wrappers with submit/change events and reset/validate handles.
- Layout config: half-width fields, titled groups, per-field help text.
- `form-change` snapshots and opt-in `validateOnChange` with focus-safe live errors.
- Single-file browser build (`dist/form-uploader.global.js`) for script-tag use.
- Documented Angular and server-rendered (Django/Flask) patterns.

## 0.1.0

- Initial release: framework-agnostic core, `<form-uploader>` element, validation, multi-image upload, CSS-variable theming.
